Privacidade

O Renova.AI guarda só o necessário para funcionar.

O que guardamos

Do aluno: nome, WhatsApp, mês em que começou a treinar, meses de pausa e o registro de cada mês renovado.

Anamnese do cadastro: objetivos, rotina (experiência com treino, sono, trabalho, estresse), jeito de treinar e expectativas sobre as aulas, respondidos pelo aluno no link de convite.

Dados de saúde: lesões, condições de saúde, remédios de uso contínuo e liberação médica são dados pessoais sensíveis pela LGPD. Só são guardados quando o aluno autoriza, a etapa pode ser pulada, e servem apenas para o personal adaptar os treinos com segurança.

Do personal: nome, e-mail, senha (protegida), chave Pix, foto enviada para a imagem de conquista e as frases escolhidas.

Para que usamos

Para mostrar a trilha do aluno, gerar o Pix da renovação, permitir que o personal envie lembretes pelo próprio WhatsApp e ajudar o personal a conhecer cada aluno. Os dados do aluno, incluindo a anamnese, ficam visíveis apenas para o personal que o convidou.

O que não fazemos

Não vendemos dados e não enviamos mensagens automáticas. O pagamento das mensalidades vai direto do aluno para o personal. Só a assinatura do personal no Renova.AI é processada pelo Mercado Pago.
